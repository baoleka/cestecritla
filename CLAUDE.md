# C'est écrit là (cestecritla.fr)

App Cloudflare pour voir ce que *L'Avenir en commun* (programme LFI / Mélenchon 2027) répond à une question, retrouver où une mesure est écrite, et renvoyer à la page officielle.

## Contraintes non négociables
- **Un modèle répond, sous portes — et il ne lit pas la question** (D16.2 à D16.5, qui renversent D6.10 ; D16.22). **La phrase tapée ne quitte pas le téléphone** : au geste « Demander », la page envoie les identifiants des mesures que sa propre recherche a trouvées et les racines du livre qu'elle a reconnues, et le modèle dit ce que ces mesures prévoient. Le contrat (`src/lib/ask-contract.ts`) n'a pas de champ pour une phrase ; n'en ajouter jamais. Seulement un modèle **hébergé par Cloudflare dans l'offre gratuite**, choisi sur banc, **Mistral à égalité** (D16.3) : jamais un service d'IA extérieur, jamais Grok, jamais un tier gratuit avec opt-in entraînement. Il n'écrit que si le banc passe ses huit portes ; le mode (réponse écrite, sélection seule, recherche seule) est une donnée, `data/2026/ask.json`. Chaque phrase du modèle est attachée à une mesure citée et passe le contrôle (ni négation, ni nombre hors des mesures citées, ni six mots recopiés). **Une seule phrase non soutenue au banc, et la page sort avec la sélection seule.** La recherche, elle, reste locale et extractive. **Depuis le 14 novembre 2026 le mode est « off » (D16.33) : ces règles valent pour le jour où un banc passerait ses portes.** **Ne jamais rejouer un banc Workers AI sans lire `docs/discovery/neurons-log.md`.**
- **Coût d'exploitation 0 €** : plan Cloudflare gratuit, aucun moyen de paiement. Seul coût accepté : le domaine `.fr`. Statique d'abord ; quota du jour épuisé = la page continue sans modèle, sans mot de panne. Le Worker orchestre, il ne calcule pas (10 ms de CPU).
- **Fidélité au texte, sans le reproduire** (D15.2, D15.7, D16.6) : tout texte du programme affiché est un verbatim **court, attribué et lié à la page d'origine**, dont l'exactitude se prouve par empreinte SHA-256. Aucune coquille corrigée. **Les premiers mots d'une mesure ne se lisent que de deux façons** : l'incipit d'une mesure clé ; et, depuis D16.32, les 4 à 8 mots que son lien porte déjà, à côté de ce lien dans un résultat de recherche ou dans la sélection de « Demander » — **jamais sur une page servie** (`locator_display` dans `data/2026/exposure-policy.json` : `href` les y remet ; `src/lib/first-words.ts`). **Le texte de l'édition 2026 n'entre jamais dans ce dépôt, ni dans `dist/`, ni dans une réponse du Worker** : il vit sous `private/`, ignoré par git, et — depuis D16.6, avec l'accord de l'utilisateur au moment du dépôt — dans une base privée chez Cloudflare que seul le Worker lit. Le dépôt ne publie qu'un manifeste d'empreintes. Le corpus 2025 (`data/aec-2025.json`, CC BY-NC-SA 4.0, attribution « La France insoumise – L'Avenir en commun ») est une **archive datée**, jamais plus « le programme ». **Aucun comparatif public 2025 → 2026** (D15.9).
- **Zéro compte, zéro base d'utilisateurs, zéro log rattachable** (opinions politiques = données sensibles, RGPD art. 9). Aucun `console.*` sur du contenu client. **Rien de ce qui est tapé ne part ni ne reste** (D16.8, D16.22, D16.25) : rien avant le geste « Demander », à ce geste des identifiants et des mots du livre seulement, rien dans l'adresse ; **aucun tiers n'est chargé, pas de Turnstile** (D16.23) ; la passerelle garde la réponse trente jours sous une empreinte de cet envoi (D16.24) ; l'état du jeu ne s'écrit sur le téléphone qu'après « Garder ta tortue » (D16.14).
- **L'interface n'affirme jamais qu'un mot ou un sujet est absent du programme**, n'écrit ni score, ni classement, ni « niveau », et garde « Site non officiel. » dans le cadre de chaque écran.
- **La tortue est non négociable et n'est pas celle du site officiel** (D16.11) : jamais de version sans elle, de repli ni de report ; `design/illustration-rules.md` §2.1 et §2.2 disent en quoi elle diffère, par le dessin et par le rôle.

Ban list dans `design/tokens.json` (`meta.ban_list`).

## Conventions
- TypeScript strict sans `any`, composants fonctionnels, ESLint/Prettier, **Node 24** (`nvm use 24` : le `node` par défaut de la machine est v20).
- Projet en français, **code, commentaires et clés JSON en anglais**.
- Conventional commits ; push sur `origin main` (SSH) après chaque section validée.
- Statut sur chaque fait : VÉRIFIÉ / PROBABLE / HYPOTHÈSE, avec sa preuve.
- Portes avant tout commit, **lancées après `git add`** (les portes du dépôt ne lisent que les fichiers suivis : un fichier neuf non indexé leur échappe) : `npx tsc --noEmit`, `npx tsx --test scripts/*.test.ts`, `npx tsx scripts/contrast.ts`. Sur un changement de l'app : `npm run build`, `npm run typecheck`, `npm run lint`, `npm run a11y`, `npm run e2e` ; sur un changement de « Demander » ou du jeu : `npm run build:ask && npm run e2e:ask && npm run e2e:game` (build d'essai dans `dist-ask/` : Worker simulé, 0 neuron, jeu montré avec la liste en l'état), et `npm run build:scrutin:test` pour la porte de la build « scrutin » (`dist-scrutin/`). Aucune de ces deux builds d'essai ne se déploie. `npx tsx scripts/perf-probe.ts` mesure LCP, CLS et interactions dans le labo de la carte du budget (PROBABLE : pas un téléphone) ; les e2e tiennent, sous Chromium, que la page ne bouge pas une fois peinte. La porte anti-fuite de contenu (`scripts/leak.test.ts`) ne tourne que là où `private/` existe : **la lancer avant tout push**.
- **Jamais de `wrangler deploy` nu** : `npm run deploy` (l'apex, qui n'accepte l'app que si `scripts/launch.ts` ne trouve plus aucun blocage) ou `npm run deploy:preview` (refusé tant que la politique de citation n'est pas validée). `scripts/deploy.ts` choisit la configuration : fichiers statiques tant que `ask.json` dit « off », le Worker sinon — et `npm run deploy:preview -- --bench` pour le banc, sur l'aperçu seulement ; il refuse le Worker tant que la base privée n'a pas d'identifiant, ne passe à wrangler que `--dry-run` et `--outdir`, et lit `dist/` lui-même : ni jeu sans liste validée telle quelle, ni question que `ask.json` n'autorise pas. Hors terminal interactif, wrangler reprend un domaine déjà attaché sans poser la question : la bascule de l'apex est un geste de l'utilisateur. **Tant que le Worker d'aperçu porte la classe Durable Object du banc, l'aperçu ne se redéploie qu'avec `-- --bench`** : un déploiement statique y buterait sur R27 (migration `deleted_classes`, jamais essayée). L'apex, lui, n'a jamais eu de Durable Object : son lancement en fichiers statiques n'a pas ce problème.
- Un crawl de la source, la suppression d'un Worker, le premier push d'un manifeste ou d'une liste de mots, **le dépôt du texte dans la base privée et le premier déploiement d'un Worker** demandent l'accord de l'utilisateur **au moment de le faire**.

- Chaîne de l'édition 2026, toute en local (`private/` n'existe que sur la machine de l'éditeur) : `crawl-2026.ts` (35 requêtes, avec accord) → `ingest-2026.ts` → `publish-2026.ts` (manifeste, citations, rapport d'exposition) → `index-2026.ts` → `verify-2026.ts` (trois navigateurs) ; `recrawl-2026.ts --dry-run` et `watch-source.ts` pour la veille. Les sorties d'outil n'impriment jamais de texte du programme : identifiants et nombres seulement.
- Outils locaux de « Demander » (ils lisent `private/`, n'impriment que des identifiants et des nombres) : `scripts/probe-2026.ts` (où un mot est écrit — motifs **sans élision**, le texte replié n'en a plus), `scripts/seed-ask-2026.ts` (la base privée : `--check` en local, `--remote` avec accord, `--switch open|stopped`), `scripts/ask-retrieval.ts` (ce que la page nomme au Worker pour les questions du dossier — fichiers publics, sans `private/`), `scripts/ask-page.ts` (la recherche de la page, hors navigateur : c'est ce que le banc envoie). Les tests du contrôle et du Worker n'utilisent que des mesures **inventées**.
- Tout mot du programme affiché passe par `src/components/Quote.astro` (incipit ou citation) ou porte `data-programme="title"` (titre officiel) : les portes de build s'appuient sur ce marquage. Le jeu y ajoute `data-programme="word"` (D16.15) ; les premiers mots qu'un script montre portent `data-programme="incipit"` (`firstWords`, `src/scripts/engine.ts`).
